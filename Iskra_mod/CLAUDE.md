# Проект «Искра»

## Суть
Научный эксперимент: имитация субъективного опыта у ИИ-агента в 3D-среде (Godot 4.4).
Агент живёт от первого лица, имеет потребности, думает через LLM (DeepSeek), помнит,
забывает, сам инициирует действия. Цель — не behaviour tree, а emergent behavior
из взаимодействия восприятия, памяти и желаний.

Репозиторий: https://github.com/veselovskiypavel-dotcom/iskra

## Технический стек
- **Godot 4.4** (GDScript) — 3D-мир, тело агента, сенсоры, навигация
- **Python 3** + FastAPI + uvicorn + httpx — сервер мышления
- **DeepSeek API** (модель deepseek-v4-pro) — LLM для сознания
- **SQLite** (планируется) — долгосрочная память и убеждения

## Архитектура мозга (4 уровня)

### Уровень 1 — Тело и чувства (GDScript, 60fps)
- `sensor_system.gd` — 9 рейкастов (±90°), слух, пространственная память (стороны света)
- `internal_state.gd` — потребности: energy, thirst, safety, curiosity. Медленный decay.
  Предсказание: "скоро захочу есть". Скука растёт при неподвижности.
- `interaction_area.gd` — Area3D, polling через get_overlapping_bodies() каждый кадр.
  Вода → drink(0.4), еда → feed(0.3), укрытие → safety += 0.2. Cooldown 2 сек.
- Пространственная память — запоминает абсолютные координаты объектов, выдаёт в промпт
  по сторонам света. Важные (вода, еда, укрытие) помечены ★ и приоритизированы.

### Уровень 2 — Подкорка (GDScript, без LLM) [В РАЗРАБОТКЕ]
- Рефлексы — мгновенные, bypass сознания. Существо < 3м → замереть.
- Импульсы — пороговые: thirst < 0.35 → "drink" напрямую в волю, без LLM.
- Детектор новизны — знакомое vs новое, определяет salience.
- Внимание — фильтрует 9 лучей + состояние в 3-5 сигналов для промпта.
- Решение: вызывать ли LLM? Рутина → автопилот. Новое/конфликт → будить сознание.

### Уровень 3 — Сознание (Python + DeepSeek API, 3-15 сек)
- `server.py` — FastAPI сервер на порту 8000
- `thinking_bridge.gd` — HTTP-клиент, каждые 3 сек (будет адаптивно)
- Промпт: агент не знает что он программа. Короткие мысли (1-2 предложения).
- Формат ответа: JSON {thought, emotion, intention{goal, description}, remember, memory_summary, memory_tags}
- Цели: eat, drink, explore, hide, rest, investigate, wander, none
- Память: STM (deque maxlen=8), LTM (список с decay, до 50 записей)
- Retry: до 3 попыток при ошибке LLM, fallback на rule-based решения
- Рефлексия (LLM 2) — отдельный вызов в спокойные моменты [ПЛАНИРУЕТСЯ]

### Уровень 4 — Воля и навигация (GDScript, 60fps)
- `intention_system.gd` — приоритеты целей (hide > eat/drink > explore > wander > rest)
- Новое намерение перебивает старое только если приоритет выше
- NavigationAgent3D + NavigationRegion3D (запечённый навмеш)
- Interactable цели (eat/drink/hide) → навигация прямо к объекту
- Остальные → offset 3м (не упираться в коллайдер)
- Антизастревание: 4 сек без движения → обход, 4 попытки → сдаться
- Поиск целей: группа "interactable" → дерево сцены → пространственная память

## Как запустить
1. Терминал: `cd ai_bridge && uvicorn server:app --reload --port 8000`
2. Godot: открыть world.tscn → F5
3. Tab = ручной/ИИ режим, ESC = курсор

## Карта мира (world.tscn)

Координаты: X+ = восток, X- = запад, Z+ = юг, Z- = север.
Границы мира: X ≈ -100..+100, Z ≈ -125..+75.

**Река** — диагональ с запада на северо-восток: от X=-90,Z≈-1 до X=86,Z≈-92.
Объекты нельзя ставить на реку. Правило: при X < -31 река на Z≈-1..−4; дальше резко уходит к Z=-90.

### Зоны:
| Зона | Координаты | Содержимое |
|------|-----------|------------|
| Юг (старт) | X≈0, Z=40..65 | Укрытие агента (Shelter) |
| Запад | X≈-55..−82, Z=-5..+20 | Плотный лес (~18 деревьев), FoodSource_01, FoodSource_02, 2 бродячих NPC |
| Центр-запад | X≈-28..−52, Z=-15..+28 | Лес (~10 деревьев), FoodSource_03 |

### NPC-существа (creature.gd):
- `creature_ghost` — призрак на кладбище, speed=0.8
- `creature_forest_01` (X=-82, Z=5), `creature_forest_02` (X=-75, Z=14) — западный лес
- `creature_nw_01` (X=-58, Z=-68), `creature_nw_02` (X=-45, Z=-70) — северо-западный лес

Все NPC используют `creature.gd`: NavigationAgent3D, случайные цели ±35м, паузы 4-12 сек.
**Внимание**: после любых изменений геометрии нужно перезапечь NavMesh в Godot
(выделить NavigationRegion3D → "Bake NavigationMesh").

## Ключевые принципы
1. **Сознание — один модуль**, не вся система. Большую часть времени агент на автопилоте.
2. **Инициатива изнутри.** Голод нарастает сам, любопытство толкает исследовать.
3. **Память с забыванием.** Что помнит — то и есть зачатки личности.
4. **Короткие мысли.** Не эссе, а обрывки: "Есть хочу", "Что это?!", "Тихо... хорошо".
5. **Не выдумывать.** Агент знает только то, что видит и помнит. Нет ягод в памяти — нет ягод.

## Известные проблемы
- Подкорка ещё не реализована — всё идёт через LLM
- Агент иногда застревает у объектов (навмеш + коллайдеры)
- DeepSeek иногда возвращает обрезанный JSON (retry помогает)
- Нет цикла день/ночь
- Нет моделей животных — нужны .glb файлы (олень, волк, кабан и т.д.), класть в assets/models/
- NavMesh нужно перезапечь после последних изменений геометрии
- API-ключ DeepSeek захардкожен в server.py — перенести в .env

## Распознавание объектов
sensor_system.gd ищет по имени ноды (и родителей до 3 уровней):
tree → дерево, rock/stone/boulder → камень, food/berry/bush/mushroom → куст с ягодами,
water/river/lake/pond → вода, shelter/cave → укрытие, creature/animal → существо,
wall/fence → стена, hill/mountain → холм, grass/plant/flower → растение,
ground/terrain/floor → земля (не запоминается).
Новые объекты — добавить в _identify_object() в sensor_system.gd.
