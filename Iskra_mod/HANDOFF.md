> Рабочая заметка для следующей сессии. Дата последней правки: 2026-11-22 (ключ в .env, мод в git; в игре с 2026-07-01 не проверяли).
>
> **🎬 КОНЦЕПЦИЯ (поворот 2026-06-30):** не научная симуляция мозга, а **развлекательный
> контент**. Симы The Sims 4 под управлением РАЗНЫХ LLM, социальные эксперименты: общаются,
> обижаются, спорят, шутят, достигают общих целей. Поведение живое и правдоподобное, БЕЗ
> биологических усложнений (отказались от 4-уровневой модели мозга, подкорки, рефлексов,
> theory-of-mind). Вся сложность — в **социальный промпт** и многоагентное взаимодействие.
>
> **СТАТУС:** фундамент одиночного поведения готов. Сим ходит, ест (где есть готовая еда),
> ходит в туалет, спит, смотрит ТВ, сам переключает цели. LLM может брать прямой контроль
> через меню действий (гибрид). Дальше — Модуль 4 (социалка, ядро продукта).

## 🚀 Сборка / запуск / логи

**Деплой мода** (из корня `Iskra_mod`):
```bash
python -c "
import zipfile, os, py_compile
src='iskra_sims'
out=r'C:\Users\Alina\Documents\Electronic Arts\The Sims 4\Mods\iskra_sims.ts4script'
for root,_,files in os.walk(src):
    for fn in files:
        if fn.endswith('.py'): py_compile.compile(os.path.join(root,fn), doraise=True)
with zipfile.ZipFile(out,'w',zipfile.ZIP_DEFLATED) as zf:
    for root,_,files in os.walk(src):
        for fn in files:
            if fn.endswith('.py'):
                fp=os.path.join(root,fn)
                zf.write(fp, os.path.relpath(fp,'.').replace(os.sep,'/'))
print('deployed', os.path.getsize(out))
"
```

## ✅ Что сделано

Движение работало с pie_menu. Дальше — чистка восприятия, баг-фиксы по логам,
визуализация мыслей, осознание обстановки, гибридный контроль.

1. **Чистая перцепция (perception.py)** — `_nearby_objects` больше не отдаёт сырые имена
   классов движка. `_identify_object()` маппит в категории (холодильник/ТВ/кровать/цветок/
   бревно с лягушками…), важные помечены `important=True` (★). Дубли свёрнуты в один пункт
   со счётчиком (`цветок (×9)`), `prototype`/декор отфильтрованы. Неизвестные — чистятся
   через `_prettify_unknown` (emergent-открытие сохранено). Рендер `★`/`(×N)` —
   в `server.build_user_prompt._vis_line`.
2. **🔥 ФАНТОМ-ПОЖАР ПОЧИНЕН (perception.py)** — `fire_alarm` (настенная сигнализация)
   содержит "fire" → детектор каждый тик видел «пожар» в 6м → сим в вечной панике убегал
   из дома. Добавлен `_NOT_REAL_FIRE = (alarm/sprinkler/extinguisher/detector/smoke)`.
   **Это была причина всей «боязни пожара» через несколько сессий.**
3. **🍽 eat без picker (action.py)** — холодильник на лоте не имеет `GrabSnack/GrabFood`,
   код доходил до `fridge_Cook` → всплывало окно выбора блюда (блокировало автономию,
   игрок выбирал руками). Теперь `_eat` приоритизирует автономные `Dish_Collection…`/
   `fridge_GrabDrinkAutonomously`, а готовку (`_COOK_PICKER_AFFORDANCES`) исключает.
   Добавлен параметр `exclude=` в `_push_first_affordance`.
4. **picker_* заблокированы глобально (action.py)** — `_SKIP_PREFIXES += picker_/simPicker`
   (открывали UI-окна выбора). cook-picker исключён и из investigate/explore/wander.
5. **Канал МЫСЛЕЙ (display.py + control.py)** — `show_thought` показывает мысль сима
   уведомлением с портретом (`💭 эмоция` + текст), дедуп по тексту. Вызов в `_tick`
   на игровом потоке. Видно ТОЛЬКО нам — это не восприятие других симов.
6. **Осознание обстановки (perception + server)** — раньше промпт говорил «стою → действие
   провалилось» даже когда сим успешно смотрел ТВ (сидит неподвижно) → LLM думал «ТВ сломан».
   Теперь: `current_action` (человеческий ярлык «смотрю телевизор» + `busy`), блок «Что я
   сейчас делаю», тренды потребностей (↑/↓). «Провал» показывается ТОЛЬКО когда реально idle.
   + правила в промпте: не игнорировать людей рядом, не жаловаться при ↑.
7. **🐰 Rabbithole-нора (action + control)** — `explore` хватал `object_sim` и пушил
   `debugImmediate_rabbitHole` → сим исчезал из мира (перцепция слепла, время летело).
   Фикс: `_SKIP_PREFIXES` debug_→debug, `_SKIP_SUBSTRINGS=(rabbithole)`, симы исключены из
   `_collect_interactable_objects` (`is_sim`), аварийный выход из норы в `_tick`.
8. **🚽 Туалет: защита маршрута (control.py)** — `bladder` пушил ToiletSit (guaranteed), но
   LLM в панике тут же менял цель (bladder→explore) пока маршрут только строился → `_clear_queue`
   убивал недостроенный поход, и так по кругу. Фикс: `_protect_until` — пока идёт долгое/срочное
   действие, LLM не может перебить его другой целью (PROTECT_TICKS=10).
9. **💧 eat больше не «пьёт воду» (action.py)** — на пустом холодильнике отрабатывал только
   `fridge_GrabDrinkAutonomously`: голод почти не падал, а пузырь рос быстро → зацикливание. Напиток
   (`_DRINK_AFFORDANCES`) исключён из eat. На пустом холодильнике eat честно вернёт «нет еды».
10. **🕹 ГИБРИДНЫЙ КОНТРОЛЬ (perception+server+action+control)** — LLM теперь может брать
    прямое управление. Перцепция шлёт меню `available_actions` («Здесь я могу: [1] смотреть
    телевизор…», из `MENU_ACTIONS`). LLM ставит `action_id` → сервер резолвит против ТОГО ЖЕ
    снимка → `chosen_action {object_id, category}` → `action.execute_chosen` делает ИМЕННО это
    на ИМЕННО том объекте. Если `action_id=null` — прежний автопилот по goal. Сам выбирает
    уровень вовлечённости (как человек: рутина на автомате, важное — осознанно).

### Что подтвердилось в тестах
- Сим ходит, сам сходил в туалет (до фикса метания), проснулся, смотрит ТВ, переключает цели.
- Визуализация мыслей работает отлично — она и вскрыла слепые зоны (ТВ «не работает», игнор гостя).
- Открытый вопрос: «завис при желании спать вне дома» — маршрут к кровати с улицы мог молча
  провалиться. Также: туалет из ДВОРА может не строить маршрут в дом (закрытая дверь?) —
  если после фикса защиты он всё равно не доходит, смотреть появляется ли ToiletSit в `running`
  и пропадает (route-fail) vs сразу None.

## ⚠️ Известные нюансы окружения

- **Холодильник на текущем лоте без `GrabSnack/GrabFood`** — есть только готовка (picker).
  Теперь готовка исключена из автономного `eat` → на этом лоте голод автономно закрыть нечем.

  на сырой `UiDialogNotification` (TODO, пока не сделан).

- Модель LLM: `deepseek-v4-pro`, `max_tokens=800`, `temperature=0.8`.
  Изредка обрезанный JSON от LLM (`max_tokens`) — retry в server.py вытаскивает.
- Управляется только active sim (`services.active_sim_info()`), его автономия глушится
